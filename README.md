# ProyectoMultiplataforma

## Escuelita (Node + Express + EJS + Sequelize)

### Requisitos
- Node.js
- PostgreSQL

### Configuración
1. Entra a `Escuelita/`
2. Copia `.env.example` a `.env` y ajusta valores
3. Instala dependencias: `npm install`
4. Inicia: `npm start`

### Notas
- Los assets del frontend se sirven bajo `/assets` (CSS/JS).
